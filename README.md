# Skills

A growing collection of reusable AI agent skills. Each skill lives in its own folder and includes a self-contained `SKILL.md` with its purpose, workflow, and sources.

## Available skills

| Skill | Purpose |
| --- | --- |
| [IDEO-inspired product design](ideo-product-design/SKILL.md) | Frame human needs, explore distinct physical-product concepts, build useful prototypes, and plan evidence-based iteration. |
| [Pyramid writing](pyramid-writing/SKILL.md) | Write clear executive emails, memos, proposals, and presentation storylines using Barbara Minto-inspired answer-first reasoning. |
| [Carnegie-inspired communication](carnegie-communication/SKILL.md) | Prepare conversations, requests, feedback, and disagreements with sincere interest, clear intent, and respect. |
| [Jobs to Be Done](jobs-to-be-done/SKILL.md) | Investigate the circumstances and desired progress behind a purchase, switch, or decision against adoption. |
| [Strategy kernel](strategy-kernel/SKILL.md) | Connect a diagnosis of the central challenge to a guiding policy and coherent actions. |
| [Behaviour change with COM-B](behavior-change/SKILL.md) | Investigate capability, opportunity, and motivation barriers to a specific behaviour. |
| [Project premortem](project-premortem/SKILL.md) | Imagine a plan has failed, investigate plausible mechanisms, and propose preventive changes. |
| [Calibrated forecasting](calibrated-forecasting/SKILL.md) | Define resolvable questions, estimate probabilities with evidence, and track updates and outcomes. |
| [Principled negotiation](principled-negotiation/SKILL.md) | Prepare interests, options, objective criteria, and a feasible alternative to agreement. |
| [Creative problem solving](creative-problem-solving/SKILL.md) | Reframe a challenge, generate distinct possibilities, and develop promising concepts. |
| [TRIZ-inspired invention](triz-invention/SKILL.md) | Model technical contradictions and explore mechanisms that could overcome a design tradeoff. |
| [Innovation experiments](innovation-experiments/SKILL.md) | Turn consequential product or business assumptions into decision-focused tests. |
| [First-principles thinking](first-principles-thinking/SKILL.md) | Separate facts and requirements from assumptions, then rebuild alternatives from the necessary functions. |

## Use a skill

Open the skill folder and use its `SKILL.md` with an agent that supports skills, or provide the file as instructions for your task.

Example task:

> Use the IDEO-inspired product design skill to rethink a shopping cart. Explore different concepts, explain the tradeoffs, and prototype the strongest direction. Separate assumptions from observed evidence.

Additional examples:

- Use `creative-problem-solving` to generate materially different ways this product could work, then develop the strongest directions.
- Use `triz-invention` to investigate how this design could be compact during transport and stable during operation.
- Use `innovation-experiments` to identify the assumption we should test before expanding this pilot.
- Use `jobs-to-be-done` to prepare interviews about why customers chose an alternative.
- Use `strategy-kernel` to turn this growth ambition into a focused strategy with explicit tradeoffs.
- Use `behavior-change` to investigate why users stop during onboarding.
- Use `project-premortem` to review this launch plan and propose changes for the most consequential failure mechanisms.
- Use `calibrated-forecasting` to turn this prediction into a resolvable question and an evidence-based estimate.
- Use `principled-negotiation` to prepare a supplier discussion, including my feasible alternative if we do not agree.
- Use `first-principles-thinking` to examine which parts of this design are necessary and which are inherited assumptions.

## Choosing skills

Choose the skill for the decision at hand. Jobs to Be Done investigates choices in context; COM-B investigates barriers to a specified behaviour. Creative problem solving expands possibilities; TRIZ examines technical conflicts; innovation experiments investigates uncertain claims. IDEO-inspired product design supports the broader human-centered product process.

First-principles thinking examines the foundations of a problem and rebuilds possible approaches. Use it when an inherited assumption may be constraining the decision; it does not replace domain evidence or user requirements.

Combine skills when useful, rather than requiring every task to pass through the whole collection. For example, investigate a customer choice with Jobs to Be Done, explore concepts with creative problem solving, and design a test with innovation experiments. Use pyramid writing when the resulting recommendation needs clearer communication.
